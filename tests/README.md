# 逻辑检查

使用 Python 和 `lupa` 的 Lua 5.1 运行时。在工作区根目录运行：

```powershell
python -m pip install --target .tools/python lupa
python tests/run_checks.py
```

本工作区已在 `.tools/python` 准备好检查依赖，不属于上传内容。

检查包含：全部 Mod Lua 文件语法、十四项设置的默认值、无标准库的原版 modinfo 沙箱、中英自动识别及手动覆盖、语言保存和异步加载、简介重建及配置返回时的刷新、选项说明、禁止登陆提示、其他 Mod 隔离、旧玩法设置继承、非海难世界隔离、七档宝石倍率与概率上限、第五次挖宝保底、四季时序、赌博机岛边界及读档、蜘蛛巢搬动数量、章鱼王动画锁及食物每日额度。

这些检查使用模拟的游戏对象，不会启动游戏或修改存档。仍需在游戏内确认设置界面、交易动画和完整游玩行为。


1.t 新增检查：七个新开关及默认值、缺少或未启用哈姆雷特时安全隔离、20种怪物等概率分配且总数不变、排除无辜动物、船长挖宝、不带电雷鸟及存档状态、植物材料1至2个、拆解配方、早期世界初始化的室内市长、商店角等概率上架、三栋房屋门槛、盗贼调用原版逻辑、关闭及读档行为、藏宝限定初始岛（不含可登陆的赌博机岛）、地面鱼骨吸入及释放。

若本机存在游戏源码，还会直接执行原版拆解法杖和盗贼管理器，检查单块拆解及消耗、原版钱币/背包计数、城市地皮、昼夜概率、掩体、已有盗贼重现、存档引用和击杀冷却，并检查使用的预制物文件存在。默认源码路径为 `D:/soft/Steam/steamapps/common/dont_starve/data`，可用环境变量 `DS_DATA_DIR` 指定；其他机器缺少源码时仅跳过该集成检查。当前共15组检查。
