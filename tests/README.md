# 逻辑与原版脚本检查

使用Python和lupa的Lua 5.1运行时：

```powershell
python -m pip install --target .tools/python lupa
python tests/run_checks.py
```

依赖放在`.tools/python`，不上传工坊。本机原版源码默认路径为`D:/soft/Steam/steamapps/common/dont_starve/data`，可用`DS_DATA_DIR`指定；缺少源码时跳过原版集成部分。

共22组检查，覆盖：

- 配置默认值、中英文、modinfo沙箱、语言保存及界面刷新、其他模组和非海难世界隔离。
- 本岛所有挖宝方式共用出金记录、前四次任一次出金、第五次保底、奶奶排除、船长生效、世界存读档、关闭仍记录。
- 幸运帽黄绿宝石概率、原版表不被修改、倍率封顶；原版铲子、风向标、船炮和炸弹挖宝路径。
- 70天/原版季节、赌博机岛边界、蜘蛛巢1至5个的不足搬动和位置间距。
- 章鱼王交易动画锁、食物每日额度、昼夜切换及存读档；鱼骨只吸地上物品并正常释放。
- 哈姆雷特内容依赖、20种攻击型生物均匀抽取、植物材料数量、不带电雷鸟及其原版电光创建流程。
- 原版拆解法杖、商店库存、市长、盗贼钱币和地皮条件、掩体、昼夜概率、原版冷却及藏宝范围。
- 原版室内进出、移动、存读档、随从和出门落点；原版传送器的随机偏移、回调和即时落点校验；原版落水救援资格、物资落点、救生衣消耗及推进一天。
- 两套商店商品/价格/货架图集及资源文件；只显示正数倒计时、首雨状态保存。

这些检查不会启动游戏或改动玩家存档。商店图像、动画、地图生成和完整游玩仍需在游戏内确认。
